# T2 — Orchestration core: the spawner MCP decides, the skill explains

Owner: AutoOS L1-main (control-plane lanes, one at a time). Goal: agents never decide what to spawn on which model; the
`autoos-agent` MCP does, from a card, deterministically, and records evidence a reviewer can trust.

## Order
T2-ONEPATH → T2-RECORD → T2-BUDGET → T2-CUTRUN → T2-WATCH → T2-RULES → T2-SKILL → T2-COMPACT; T2-CANARY and T2-LEAN
fit between. Each lane: TDD (failing test first), local-green, 2 cross-family reviews + Sonnet final, merge only on green main.

## Production proof (not just unit tests)
After T2-ONEPATH..T2-WATCH: one real day of lanes where every spawn came through the MCP (0 hand-rolled spawns in logs),
every DONE line generated from run records, and a deliberately killed worker re-spawned automatically.
