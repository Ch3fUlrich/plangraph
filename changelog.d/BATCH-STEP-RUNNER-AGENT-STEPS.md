The step runner's write, review and fix steps run over the native writer `Driver` (`native_writer_steps`): write is the first writer turn and needs a commit beyond the base, review is one review run on the stamped head mapped to accept or request changes with its text kept per run, and fix resumes the same writer session with those findings. A usage limit is booked and stops later turns. The old native writer loop is not removed yet; that part is a separate slice.
