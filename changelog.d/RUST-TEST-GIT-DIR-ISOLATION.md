Rust Git test fixtures now share the isolated command helper, including the remaining hook, policy, repo-sync, worker-core and spawnd helpers. Inherited Git repository redirects cannot route fixture init, config or commits into a pushing repository. A subprocess regression checks sentinel config, HEAD and worktree registrations under all four hook redirect variables. The shared helper also refuses the source repository and its linked worktrees; The existing Rust registry guard also watches config bytes and scopes registration checks to the fixture root, preserving detection while other sessions add worktrees. Python already guards source config and fixture worktree registrations through tests/conftest.py's session fixture.

After merging and updating hook checkouts, each host must run `git worktree prune` and remove stale fixture worktrees registered under `/dev/shm` and `/mnt/data/plangraph/tmp`. This requires host-local cleanup after the merge.
