- pg-disk-hygiene makes progress on every run: when the root process reader is missing or older than `--hygiene-references`, the inventory comes from this user's own processes (`/proc/<pid>` without privileges) and the report names the reader fault once in `process_reader`; container processes in another mount namespace map their paths through both mount tables instead of voiding the inventory; protection loads pins, run records and unit references once per refresh interval, and a unit run from the home directory no longer pins every tree below it.
- Idle sweep without disk pressure: Cargo targets nested in a shared target root (`<shared>/<name>`) are capped like pool slots and removed whole after 6 h idle, `pg-affected-*` selector scratch and dead-pid `/dev/shm/pg<pid>-*` pytest run dirs go after 6 h idle (test-fixture repositories, future mtimes and read-only fixture directories inside them no longer block removal), and a build in a nested target no longer holds the shared root's own profiles. `--shm-root` names the shm root; `--tmp-root` disables the host one.
