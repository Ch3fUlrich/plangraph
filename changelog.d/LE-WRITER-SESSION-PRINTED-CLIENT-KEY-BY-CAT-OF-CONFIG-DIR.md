`pg-hook secret-read` is a PreToolUse guard that refuses cat, head, tail, sed, awk, grep without -l/-c/-q, source, an input redirect, `find -exec` and a Read or Grep path on key, token and env files of the plangraph config directory (also through a glob, `~`, `$HOME` or `..`), the ssh directory and the Codex auth file, and names the file; `ls`, `stat`, `test -s` and `wc -c` stay allowed. The batch-writer skill states the rule and the `SECRET-PRINTED <file>` status line. Install per host after the merge: `tools/hooks/install_hooks.sh --session-rust`, then register PreToolUse (matcher `Bash|Read|Grep`, onFailure block) with `sh -c 'test -x "$1" || exit 1; exec "$1" secret-read' _ DEST/pg-hook`; probe on each host with a session `cat` of a fixture key file under a temporary config home, which must answer `secret-read: refused`.
