`commit+ci` evidence on a merge commit without trailers now binds the item through the `Plan-Item` trailers of its branch range, and `merge_batch.py land` merges the batch PR with one `Plan-Item` trailer per item of every included part, so the merge commit itself verifies on green CI. The merged-on-default scan also reads every repository of the keeper config (`merge_scan` narrows it, `plangraph merge-close --repos` prints it), so an item merged in another scanned repository closes there; a key found in several repositories is refused `merge_repo_ambiguous`.
