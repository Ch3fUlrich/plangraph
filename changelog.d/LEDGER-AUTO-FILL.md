# LEDGER-AUTO-FILL

Native Codex terminal runs automatically write a private, immutable JSONL ledger row
beside their run record. `pg-spawnd ledger-report <state>/runs` prints per-UTC-day
writer totals with separate unknown counts. Token totals use Codex text summaries
or native JSON usage without counting cached input twice.

First self-contained slice under rule 3.4: batch landing rows and their fixture
remain open, as does instrumentation of legacy writer wrappers.
