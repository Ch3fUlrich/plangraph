- **LE-DISK-HYGIENE-DEFERS-ALL-CLEANUP-WHILE-ANY-BUILD-RUNS**: `pg-disk-hygiene` no longer skips every sweep and cache while any build runs on the host: a tree, target or cache is busy only when a process has its cwd, an open file, its executable or `CARGO_TARGET_DIR` inside it, a cargo lease is held, or a pin or unfinished run names it. Below the cleanup floor it removes idle Cargo targets (worktree `rust/target` untouched for 15 minutes, scratch and `fc-*` targets) largest first until free space is back above the floor and reports `kept: <reason>` per kept path; an `--apply` run that ends below the floor with freed 0 exits non-zero with an `ALERT` naming the five largest kept paths.
