The Claude fleet-session run record keeps the launching session as `parent_session` (the `--parent` name of `fleet-launch`), written only when the name is a valid session name (alphanumeric start, then alphanumeric `.` `_` `-`, at most 128 characters), so completion events reach the parent by name. No deploy needed: the field is read by the existing completion-event path and appears on the next launch after the normal binary update.
