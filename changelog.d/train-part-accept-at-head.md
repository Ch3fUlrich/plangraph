`plangraph land-train build` enforces the review gate inside `build_train`: every part needs one answer at its exact head that carries the registrar receipt run id and is either a single-seat leg (default Hydrogen, or the gpt-6.2-high leg only when `--seat-meta`, written by the launcher of the review run, records effort high, `D-6804` and another writer family; override `--single-seat`, exact leg ids) or part of the deepseek and glm pair on two different runs that no other answer claims. The refusal names the part, head, receipt run and the answers found. The train script that passes these flags is `plangraph:TRAIN-SCRIPTS-ACCEPT-DIR-SINGLE-SEAT`.
