`pg-spawnd head-gate` runs the completed-head gates of a writer (file size, new-code language, changelog and docs, commit trailers, Plan-Item keys bound to the brief, and the private scrub with the words file) over the admitted base and head, exits nonzero with the failing gate's output on a hit and writes a diagnostic record with `--record`. The native Codex driver runs the same function (`head_gate::run`, including the upstream exclusion of imported commits and the policy gate's cache lease), so the two harnesses cannot drift; Claude and Codex writer briefs render the same Run values and fast checks through one renderer, pinned by a parity test.
