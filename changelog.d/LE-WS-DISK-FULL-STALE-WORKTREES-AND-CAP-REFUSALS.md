- **NATIVE-REFUSAL-STATUS**: a spawn's launcher-visible outcome now comes from the saved run record, never from the admission snapshot. The detached supervisor reloads the exact run (the refusal exception carries its `run_id`; no error-text match), logs `SPAWN <run> <STATUS>` (`ALERT` when refused) and exits nonzero for a refusal, including one with no task. `spawn --wait` and `wait RUN_ID` share one exit rule and reply only once the record carries `ended`; a refused record with exit code 0, none or a non-integer exits nonzero. The Python MCP native spawn honours a positive `wait_seconds` the same way, and a forwarded native refusal (`origin_receipt`) sends no notification of its own, so one refusal is announced once.
