- CI builds the Rust workspace tests once into a cargo-nextest archive (job `rust`) and runs it in three slices (job `rust-test`, `Rust workspace tests (shard N of 3)`); ci-gate, the land reader and the ci-watch matrix require every slice. Every Rust test has a hang limit in `rust/.config/nextest.toml` (SLOW each 60 s, TIMEOUT after 180 s); a longer limit needs a `reason:` comment. nextest is a pinned, checksum-verified, cached download (`.github/actions/setup-nextest`). A changed Cargo.lock restores the newest Rust cache of the same toolchain.
