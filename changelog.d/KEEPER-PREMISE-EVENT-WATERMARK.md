The decision clock that orders items citing no decision now reads only recorded title, description, done-criteria and source values: a creation description, the changed side of a definition audit or criteria-ledger row, and a description that differs from its last recorded value. Metadata such as `design_ref`, unchanged resaves, migrated descriptions, carried rehome data and note text no longer move it, and an uncited item reads the clock at its creation or last recorded premise change (a rehome keeps the original). Deploy: restart the keeper service so the clock rebuilds; no migration. Existing partial-merge notes lose their shared-clock evidence, so an uncited item whose only earlier evidence was such a note has an unknown watermark and is not refused.
