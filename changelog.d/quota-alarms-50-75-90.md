Add subscription quota alarms: a 15-minute user timer reads the gateway quota_snapshots read-only and sends one routing line per 50/75/90 % threshold per window with 6 h burn rate and projected empty time (plangraph:QUOTA-ALARMS-50-75-90). A window without a snapshot for 3 h (hourly writer plus jitter) or an empty or fully stale table sends a `quota-alarm-stale` or `quota-alarm-blind` line, repeated daily, never silence. Windows with a null reset time are keyed by the start of their newest run (a refill of 10 points starts a new run) so thresholds re-arm; the state file prunes finished windows. `QUOTA_SNAPSHOT_DB` reads a read-only sqlite mount or copy directly so the unit needs no docker group; `docker exec` stays only as the fallback when the variable is unset, until the operator mounts or copies the data (design: no write path, one table, no new privilege beyond what the operator already chose).
