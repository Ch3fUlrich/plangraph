The native review command waits through the card's time budget. If the reviewer is still active, the command reports its run ID and expected end, and a local finisher writes its review file once the run completes. The next invocation for that head checks the existing run before spawning. A finished result survives retirement of its pending receipt, and a missing run can be replaced. The standalone review command reports live seats as pending and writes their verdict files when they finish. Late files distinguish missing verdicts and execution errors, and a failed seat takes precedence in the foreground result while live seats still report their deadlines.
