The mimo legs map to OmniRoute provider `xiaomi-mimo` through one row (`omniroute_provider_id`, catalog seed). The leg-state snapshot lookup uses it, so both mimo legs are reachable instead of `unreachable`; a leg whose provider is missing from the snapshot reports the id it looked up in `evidence.looked_up_provider`. The call-log alias derives from the same row and the mimo opencode provider takes the base URL and key env of the omniroute provider.
