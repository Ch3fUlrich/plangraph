The OpenCode review launch (`spawner/runner.py`) disables session sharing for every review seat and fails closed: it refuses a launch whose final config is not JSON, lacks the default deny, adds an `mcp` or `plugin` tool source, grants anything beyond the read-only policy (an extra allow, a non-checkout bash command) or does not set sharing to `disabled`, or whose environment keeps an active configuration layer (managed `opencode.json(c)`, stray OPENCODE_* names, project or Claude Code layers, config dirs outside the per-job dir) that can add tools, and records `permission_denied` with the count of refused tool calls from the run stream. The unwired Rust copy of the policy (`pg-worker` `seat_tools`) is removed so the policy has one implementation.
