`plangraph wait ci --pr N|--branch B` ends on the newest tests run of the head being `completed` (never on the check rollup), prints the run id and conclusion and has a deadline (default one hour, exit 3 with the pending run named). `plangraph wait files --status FILE --result FILE` waits on writer status files and seat results. Every wait writes `<name>.json` under `$CLAUDE_JOB_DIR/waits`, which `plangraph resume-digest JOB` lists. The Bash guard refuses a `while`/`until`/`for` loop that polls `gh` or `ssh` with `sleep`. One deadline starts before the head lookup and bounds every `gh` call and sleep; `--branch` waits on the branch tip's own run. `plangraph wait gate-alert --pr N` raises `ALERT green-without-go` for a head whose run has been green for over 15 minutes with no `GO-REQ` comment naming it. The guard looks at the command of each loop step, so a loop that only prints the words `gh` or `ssh` stays allowed.
