`plangraph wait ci --pr N|--branch B` ends on the newest tests run of the head being `completed` (never on the check rollup), prints the run id and conclusion and has a deadline (default one hour, exit 3 with the pending run named). `plangraph wait files --status FILE --result FILE` waits on writer status files and seat results. Every wait writes `<name>.json` under `$CLAUDE_JOB_DIR/waits`, which `plangraph resume-digest JOB` lists. The Bash guard refuses a `while`/`until`/`for` loop that polls `gh` or `ssh` with `sleep`.
