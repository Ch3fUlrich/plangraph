- The fleet launcher keeps a state-shadow role attached to its live session: a role with a collector (`state-shadow/ROLE.env`) gets its own settings file `launch-settings/role-ROLE.json` (lean profile, caps and the measure-only hook, rewritten at every launch, never shared with a role of equal caps), and every launch rewrites `ROLE.json` with the new session id and its transcript under any Claude project directory. The launcher updates the configuration named by the role's env file. The collector takes session and transcript each scan from the role's committed launch record (so a replacement adopted later is followed), refreshes its quota file each scan from the router's booked AGY and Codex limits and the quota snapshots, and fails the quota source when that file is older than ten minutes. `host-sync --install-env state-shadow` takes no settings files and registers no hook (a shared profile would leak it); it generates `ROLE.json` from `ROLE.seed.json` and the role's launch record.
