Add `plangraph runner plan|install|check --os linux`: an idempotent, checksum-pinned setup of the Linux self-hosted CI runner host (users, sudoers, apt, runner tarballs, Python tool-cache seed, Playwright, run-one.sh) with per-user self-checks; see docs/operations/ci-runners.md. The runner users get one fixed root apt-get command (no wildcard), and install mounts /proc with hidepid=2 so the JIT token in run.sh arguments is hidden from other users.
