`plangraph fast-checks --dispatch` places a command on the least loaded eligible registry host (memory floor met, one-minute load per CPU below 0.7) and retries once on another host when the run printed the `host_busy` reason line, which the affected-test timeout in `tools/preflight.py` now emits on a loaded host. Real test failures stay terminal; `--log` records each attempt and `--report` counts busy retries apart from test failures.
