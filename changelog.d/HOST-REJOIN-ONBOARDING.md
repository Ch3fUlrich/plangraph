A worker host that was unreachable for more than ten minutes, including a long planned maintenance window, now returns as `rejoining`, and placement refuses it until `pg-spawnd rejoin HOST` passes. The gate runs the host code sync, compares the installed binary with main and flags a difference, and settles each run marked unknown (finished, live or dead). It starts the report-only worktree sweep, checks the disk and RAM floors (flagging any floor it cannot measure) and probes the configured legs. It writes one record under the state directory's `rejoin` folder and sets the host ready; a failed step keeps the host rejoining and records the attempt.
