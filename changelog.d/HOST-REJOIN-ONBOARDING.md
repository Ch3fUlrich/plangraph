A worker host that was unreachable for more than ten minutes, including a long planned maintenance window, now returns as `rejoining`, and placement refuses it (under its registry id or any alias) until `pg-spawnd rejoin HOST` passes. The gate runs the host code sync and needs each checkout at origin/main, flags a binary or hook that differs from main, and reads each unknown run from the host's own records (live session, dead with its Keeper claim released, or terminal with its exit code). It runs the approved worktree reaper, measures the disk and RAM floors and probes the configured legs; a floor it cannot measure or a host with no leg probe blocks. It writes one record under the state directory's `rejoin` folder and sets the host ready only for the outage it reconciled; a failed step keeps the host rejoining and records the attempt.
