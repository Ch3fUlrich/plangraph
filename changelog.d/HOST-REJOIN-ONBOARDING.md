A worker host that was unreachable for more than ten minutes now returns as `rejoining`, and placement refuses it until `pg-spawnd rejoin HOST` passes. The gate runs the host code sync, compares the installed binary with main and flags a difference, settles each run marked unknown (finished, live or dead), reaps stale worktrees, checks the disk and RAM floors and probes the configured legs. It writes one record under the state directory's `rejoin` folder and sets the host ready; a failed step keeps the host rejoining and records the attempt.
