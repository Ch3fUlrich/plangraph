Add `host-sync --install-dry-run [--registry FILE] [--repo DIR] HOST FAMILY`: for a unit family it checks the unit file, the `ExecStart` binary, the `EnvironmentFile` keys and the paths they name on the host (over ssh for a remote one); for `bin:NAME` it checks the built binary and the install directory. It prints one `MISSING binary|file|env|path NAME` line per absent thing and exits 1; a complete host exits 0 with no output. This is the command `land-train deploy-plan` runs per target.
