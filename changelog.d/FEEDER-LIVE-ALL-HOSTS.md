The live writer feeder admits by free RAM: a host's new writers are (free RAM - floor) / RAM per writer, load1 only paces a host without a PSI file to one new writer per tick, and every decision's capacity line shows the numbers. The policy lists the workstation (8 writers); a host the policy does not list refuses as `unknown_host:<name>` and gets no synthetic limit. Deploy step: none beyond the normal checkout and CLI update on coding and dell; the workstation timer stays disabled (or `~/.config/plangraph/feeder.off` stays set) until the Windows RAM sampling slice is deployed, because WSL free RAM overstates what the workstation has.
