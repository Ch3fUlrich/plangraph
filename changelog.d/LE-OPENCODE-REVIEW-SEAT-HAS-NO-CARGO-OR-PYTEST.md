An OpenCode review seat now gets cargo (`~/.cargo/bin` of the launching user, read before the seat swaps HOME) and a venv with pytest on its PATH, the same venv lookup the Sonnet seat uses (one shared `review_toolchain` helper), so a counted seat can run the touched tests. The review skill treats a test command that cannot start as a HIGH finding instead of accepting on reading (plangraph:LE-OPENCODE-REVIEW-SEAT-HAS-NO-CARGO-OR-PYTEST).
