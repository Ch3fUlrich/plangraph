An OpenCode review seat now gets cargo (`~/.cargo/bin` of the launching user, read before the seat swaps HOME) and the installed service's venv with pytest on its PATH, the same lookup the Sonnet seat uses (`claude_seat.pytest_bin_dir`), so a counted seat can run the touched tests; the seat's user installs and rustup data stay reachable through the HOME swap. The review skill treats a test command that cannot start as a HIGH finding instead of accepting on reading (plangraph:LE-OPENCODE-REVIEW-SEAT-HAS-NO-CARGO-OR-PYTEST).
