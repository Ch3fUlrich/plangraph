A card whose `sandbox` is `danger-full-access`, or any value other than absent, `null` or `workspace-write`, is now refused with `sandbox_refused:` before routing, placement, forwarding, the binary probe or a run-tree lease, in the Python entry points and in `pg-spawnd` (MCP spawn and route, native spawn, the native writer's start and `writer-resume`). The refusal never echoes the card value. No deploy needed: the next `pg-spawnd` rebuild and the Python checkout carry it.
