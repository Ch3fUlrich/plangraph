- Native writer sandbox: `cargo` on the writer's `PATH` is a link to `pg-spawnd` that holds the shared Cargo lease for one command and releases it afterwards, replacing the lease held for the whole Codex turn, so a trim can run between commands. A nested Cargo command, preflight and fast checks mark `PLANGRAPH_CARGO_LEASE_HELD` and reuse their outer lease. A cancelled command strands neither the lease nor its Cargo child, and cap and trim refusals name the live holder pids (read from `/proc/locks`).
