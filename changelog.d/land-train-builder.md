`plangraph land-train build` builds a landing train from the registrar's READY parts without an LLM turn: dependency closure (a child never without its parent), a manifest with base, ordered heads, dependency graph, Git version and merge attributes, isolated Git configuration, a first-parent chain and replay proof, a build result with verified left-out reasons (`conflict`, `descendant`, `cap`), and no train while main is red or pending; the registrar rules pin observed heads and register a child only on its parent's READY head.
