A fix round for a placed native writer resumes the same Codex session on its owning host through the spawner: `pg-spawnd resume RUN_ID --prompt-file PATH [--host NAME]` and `python3 -m plangraph.spawner.cli resume RUN_ID` route the prompt to `pg-spawnd resume-local`, which starts the resume detached. The resumed turn's sandbox lists the linked worktree's git directory (`.git/worktrees/<name>`) as writable, so its fix commit lands. The owning host acknowledges a round only after the resume has reopened the run (one prompt file and log per round), and the origin receipt stays running (`resume_requested`) until the target reports that round, so `result` and `wait` never return the earlier head.
