- Native writer push: the supervisor reclaims an over-cap shared Cargo target from the host (outside the writer sandbox, under the exclusive lease) before the protected push, and the native launch caller no longer holds a shared lease until the supervisor exits. A target with a real `.git` entry, a running second build or a held lease leaves a `push_pending` receipt that names the blocker and the holder pids; a retry runs only the gates, the reclaim and the push of the same accepted head, with no writer turn and no review.
