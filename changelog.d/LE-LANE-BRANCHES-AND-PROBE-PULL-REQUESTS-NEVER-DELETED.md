- **LE-LANE-BRANCHES-AND-PROBE-PULL-REQUESTS-NEVER-DELETED (D-6771):** Add `plangraph lane-cleanup`: it deletes remote `lane/*` heads that are merged, in main (a no-op merge), or superseded by a recorded later round, keeps claimed, open-PR (head or base), checked-out and held refs, reports stale heads only, closes probe pull requests bound to an ended run (`close-probes`), pins and logs every deleted SHA for restore, and runs daily via `pg-lane-cleanup.timer`. Lane deletes (here and in `pg-worktree-sweep --delete-remote`) go through one door that runs the pre-push hook, which now accepts a delete-only push of `refs/heads/lane/*` only for a remote marked `plangraph-lane-delete=app` with a matching restore record.
