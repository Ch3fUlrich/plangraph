- `plangraph router ruling-row ROW.txt` refuses a decision row or proposal that states a `cause:`, `size:` or `time:` without a `Measured:` field. The field starts with one of our own data sources (keeper, telemetry, ledger, ci-runs, journal, decisions-log, sqlite), holds an anchor naming the result (a date or range, decision id, PR or run id) and a metric word directly before a signed number with an optional unit (`median 250ms`, `trains=63`; a time of day, an id or an HTTP status is not a value). It must be a completed measurement of ours: not one that found nothing, never ran, failed, was aborted or is pending, and it must not name another party's system or a repository that is not ours (the origin of the working checkout or `PLANGRAPH_OWN_REPOS`). Such words (and `configured`) are allowed right after a measured value, a number with its metric word, where they describe what was counted (`counted 12 aborted launches`, `counted 12 configured projects`) and not after `attempt 3` or a status; a rate such as `3jobs/hour` is not a repository; ownership comes from the named source, not from topic words, and a sentence-ending period is not a decimal point; `Unmeasured:` or another company's name alone does not count (rule 4.02). The router and oversight skills run it before a ruling is logged.
