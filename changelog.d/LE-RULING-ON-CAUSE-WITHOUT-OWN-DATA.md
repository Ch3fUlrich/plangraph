- `plangraph router ruling-row ROW.txt` refuses a decision row or proposal that states a `cause:`, `size:` or `time:` without a `Measured:` field. The field needs one of our own data sources (keeper, telemetry, ledger, CI, a query, journal or log), an anchor naming the result (a date or range, decision id, PR or run id) and a value besides the anchor, and it must not say that nothing was found; `Unmeasured:` or another company's name alone does not count (rule 4.02). The router and oversight skills run it before a ruling is logged.
