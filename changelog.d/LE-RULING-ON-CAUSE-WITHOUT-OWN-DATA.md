- `plangraph router ruling-row ROW.txt` refuses a decision row or proposal that states a `cause:`, `size:` or `time:` without a `Measured:` field. The field starts with one of our own data sources (keeper, telemetry, ledger, ci-runs, journal, decisions-log, sqlite), holds an anchor naming the result (a date or range, decision id, PR or run id) and a plain number besides it (a time of day is not one), and must not say that nothing was found; `Unmeasured:` or another company's name alone does not count (rule 4.02). The router and oversight skills run it before a ruling is logged.
