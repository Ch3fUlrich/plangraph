- `plangraph router ruling-row ROW.txt` refuses a decision row or proposal that states a `cause:`, `size:` or `time:` without a `Measured:` field. The field starts with one of our own data sources (keeper, telemetry, ledger, ci-runs, journal, decisions-log, sqlite), holds an anchor naming the result (a date or range, decision id, PR or run id) and a metric word directly before a signed number with an optional unit (`median 250ms`, `trains=63`; a time of day, an id or an HTTP status is not a value). It must be a completed measurement of ours: not one that found nothing, failed or is pending, and not another company's system; `Unmeasured:` or another company's name alone does not count (rule 4.02). The router and oversight skills run it before a ruling is logged.
