`affected_tests.py --run` ends with one line `AFFECTED rc=<n> batches=<k> failed=<m>` and exits non-zero when any batch failed, so a failing early batch can no longer hide behind a passing last one. `plangraph fast-checks --owned-worktree` now writes a receipt for every outcome (`head`, `result green|red`, one `check <label> rc= wall=` line each) and the same receipt as a git note (`refs/notes/plangraph-fast-checks`) that travels with the pushed head. `plangraph fast-checks --stamp-green HEAD` answers the push gate. The review launch, the step runner's push and the lane push refuse a head whose receipt is missing or red.
