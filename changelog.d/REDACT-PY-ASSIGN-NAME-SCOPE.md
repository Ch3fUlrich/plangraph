- **REDACT-PY-ASSIGN-NAME-SCOPE (D-5563/D-5566):** Python's plain-mode assignment rule now includes Rust's credential-name set, including prefixed or suffixed TOKEN, SECRET, PASSWORD, PASSWD, APIKEY, API_KEY, ACCESSKEY, ACCESS_KEY, PRIVATEKEY, PRIVATE_KEY and CREDENTIAL names, while retaining PG_DSN and `\w*_KEY`. The shielded pre-pass uses the same widened rule, preventing an earlier short token from exposing MY_SECRET's value. Shared synthetic LF/CRLF fixtures and mirrored MY_SECRET regressions replace D-5279 R3's accepted name-scope difference; existing fixture expectations and name-eating probes remain unchanged. Python still keeps quoted-value quotes while Rust drops them, explicitly represented by `expected`/`rust_expected` fixture fields. Plain-mode `max_tokens` and `token_count` assignments now mask values by design; source-mode assignments, Python value/separator handling, structured-key policy and Rust production behavior are unchanged.
