**V4 – Test strength**  

*Strengths* – The suite checks deep state transitions (e.g., claim → release → re‑claim, verdict‑driven state changes, immutability of DONE/cancelled items, hash‑chain head movement, batch‑apply atomicity, run‑token life‑cycle, replay idempotency). Concurrency tests validate the “single winner” guarantee. Event‑chain validation (`test_events`) inspects payloads, actors, and hash consistency.

*Weak / tautological areas* –  
- Many error‑path tests only assert HTTP status and schema (`Error`) without checking the **exact `msg`** text (e.g., `test_http_surface` verifies 403/400 codes but not the explanatory message).  
- `test_apply_ops_http_shape_and_gate` confirms that non‑router roles get 403 but does not verify that the **payload** of a successful `apply_ops` contains the expected per‑op results beyond count.  
- `test_http_surface` does not validate that the `Authorization` header case‑sensitivity check truly rejects `bearer` versus `Bearer` beyond a single request (could be expanded).  

Overall the suite exercises the behaviour thoroughly, but could be hardened by asserting more detailed error messages and response bodies.

**V5 – Harness robustness**  

*Potential race / flakiness* – `test_concurrency._race` uses a `threading.Barrier` to synchronize threads and a `join(timeout=30)`. If any thread deadlocks, the test will hang up to the timeout, which is acceptable but may produce nondeterministic failures on heavily loaded CI machines.  

*Daemon lifecycle* – The `start_local` fixture starts the keeper subprocess and polls the `/v1/health` endpoint for up to 20 s. If the keeper takes longer (e.g., under load) the fixture will abort, causing a false‑negative.  

*Temporary resources* – `tmp_path_factory` ensures unique directories per session; `keeper.stop()` cleanly terminates the subprocess and removes the temporary directory in `test_snapshot_file`. No leftover processes are observed.  

*Conclusion* – The harness is reasonably robust, but the fixed 20 s start‑up timeout could be a source of intermittent failures on slower CI runners.
